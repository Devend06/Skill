# Skills

## gerador-de-posts

Transforma uma ideia em posts prontos para **LinkedIn, Instagram, X/Twitter e Threads**, em português e no seu estilo. Entrega 3 variações por rede (história, lista, opinião...) e diz qual recomenda.

**Como usar:** instale a skill e peça algo como *"quero postar no LinkedIn que terminei meu primeiro freela"*.

**Personalize:** preencha `gerador-de-posts/perfil.md` com seu tom, público e exemplos de posts seus, ou peça *"monta meu perfil de estilo"*.

```
gerador-de-posts/
├── SKILL.md          # instruções da skill
├── perfil.md         # seu estilo de escrita
└── references/       # regras de cada rede
```
